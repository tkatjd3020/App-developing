이 앱은 중·고등학생과 대학생 밴드부가 합주할 때 메트로놈을 보다 친숙하고 편리하게 사용할 수 있도록 만든 앱이다. 별도의 메트로놈 기기를 구매하는 대신 휴대폰에 앱을 간편하게 설치해 사용할 수 있으며, 밴드부 세션 간 휴대폰을 동기화해 동시에 같은 박자를 들을 수 있다는 점이 첫 번째 차별점이다. 또한 세션과 휴대폰을 동기화해 메트로놈을 실행하면 소리가 아닌 시각 정보로 박자를 보여 줌으로써, 합주 시 연주 소리에 집중하면서도 박자를 눈으로 확인할 수 있다는 점이 두 번째 차별점이다. (동기화 시 청각적 박자 지원은 오디오 지연 이슈로 불가능함.)
